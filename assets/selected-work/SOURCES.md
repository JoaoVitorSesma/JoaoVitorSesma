# Selected work artwork sources

The images are pre-rendered compositions. Only frame reflections and an illustrative architecture pulse move; source figures and numerical content remain stationary. Static PNGs are selected for reduced motion and serve as the default fallback.

## Research

- Original project artwork, not a statistical result: https://github.com/JoaoVitorSesma/Predicao-da-Sobrevida-em-Pacientes-com-Cancer-Colorretal-IC/blob/main/Figuras/COX.png
- Colorectal cancer Kaplan–Meier plot: existing image/png output in cell 17, output 2 (zero-based) of https://github.com/JoaoVitorSesma/Predicao-da-Sobrevida-em-Pacientes-com-Cancer-Colorretal-IC/blob/main/FOSP_curvas_Kaplan_Meier.ipynb
- Both original source images are preserved byte-for-byte beside these compositions. Axes, legend, cohort label and values are unchanged. The notebook was not executed; no patient records were processed to create the artwork.

## Dashboard

- Interface reconstruction based on https://github.com/JoaoVitorSesma/Dashboard/blob/main/DFOSP.py
- The app uses local CSV and KML paths. To avoid processing patient records or modifying the app, this artwork reconstructs documented filters and view titles without numerical series, patient counts or a fabricated map. This is explicitly labeled in the image and alternative text.
- The chart area is an empty preview, not an application error or an empirical result.

## Monitor

- Architecture overview based on https://github.com/JoaoVitorSesma/codex-reset-monitor/blob/main/README.md
- Public sources → deterministic classification → event deduplication → Discord alerts.
- The pulse illustrates this documented flow; it is not a live status indicator or an actual notification.

Desktop compositions: 1200 × 600 px. Mobile compositions: 720 × 620 px. Each animated image has an eight-second loop with a long pause. Light and dark compositions share identical source data and content.
